# Batch 17 prompts (18 images)

Source: `docs/art-inventory.md` section 4, row B17. Run recipe, prompt rules and file layout: [README.md](README.md). Hi-fi painterly art, never pixel art. The three variants of a unit differ in composition and detail only, never in design. Facing sheets (down and up) name the chosen side variant as their reference (see the reference line of each entry).

Rows: `choirling`: 3, `icon_tether_moth`: 3, `icon_pitch_pot`: 3, `icon_cinder_wick`: 3, `icon_tallow_sling`: 3, `icon_reed_raft`: 3.

Shared rules used in every entry: the shared block of `art-brief.md`, then the sheet block, the texture block or the face block, as the entry says. Icons and single edge strips use the same wording with the key colour replaced (the icon block and the edge block are written from the sheet block and the edge-strip rule of `asset-contract.md` section 7; nothing else changed). Each entry ends with `Image size`.

### b17_choirling_v1

- Job id: `b17_choirling_v1`
- Output file: `tools/source_art/choirling_v1.png`
- Key colour: pure magenta `#FF00FF`
- Size: 1536x1024 (landscape), 3 rows, 8 poses, facing `none (one direction)`
- Reference images: `tools/source_art/hush_spitcap.png` (style and design; attach them to the image call)
- Variant: 1 of 3
- Accepted name after the cull: `tools/source_art/choirling.png`

```text
Original game art for "Wickwarden", a painterly top-down adventure. Hand-painted storybook illustration style with visible brush strokes and soft edges, high detail, warm lamp light against deep dusk colours, low saturation except for light sources. NOT pixel art, no pixel grid, no dithering, no thick black outlines. Three-quarter top-down view, camera about 50 degrees above the ground, key light from the upper left. No text, no letters, no numbers, no labels, no frame borders, no grid lines, no watermark.

A sprite sheet on a perfectly flat, uniform pure magenta #FF00FF background that fills the whole image, with no gradient, no texture, no vignette, no floor and no cast shadow on the background. Each pose is a separate, complete figure with a wide empty gap of background on all sides; poses never touch or overlap and nothing is cut off at the image edge. Poses in one row stand on one shared invisible ground line and have the same scale. The figure is identical in every pose: same design, same colours, same proportions.

A floating singer: a round body the colour of old pale wax with a wide round mouth ringed with pale lamp-glass teeth and a faint cold glow inside, trailing pale ribbons. Seen three-quarter from above, facing the right edge. Each figure is centred in its own cell. Exactly 8 separate poses in 3 horizontal rows on a 1536x1024 landscape canvas, top row first, with a clear empty gap between the rows; all poses at the same scale, each row on one baseline, wide equal gaps inside each row. Row 1 (4 poses): hover: a floating round body with a wide round mouth, the pale lamp-glass teeth ringing it, ribbons trailing behind, four slightly different hover positions. Row 2 (2 poses): telegraph: the mouth opening wider, a faint pale ring glyph forming in front of it, two steps. Row 3 (2 poses): sing: the mouth wide open, a pale cone of sound leaving it, two steps.

Variation for this image: Neutral, clear composition.

Image size: 1536x1024.
```
