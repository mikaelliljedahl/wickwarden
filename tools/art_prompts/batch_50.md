# Batch 50 prompts (18 images)

Source: `docs/art-inventory.md` section 4, row B50. Run recipe, prompt rules and file layout: [README.md](README.md). Hi-fi painterly art, never pixel art. The three variants of a unit differ in composition and detail only, never in design. Walk sheets are drawn side first (the accepted side sheet is the design reference for the down and up sheets); action sheets name the walk sheet of their own facing as their design reference (see each reference line). Producer f (batches 48 to 59), wording and facing rules from `tools/art_prompts/PROGRESS.md` and `PROGRESS_a.md`; invented details in `DESIGNS_f.md`.

Shared rules used in every entry: the shared block of `art-brief.md`, then the sheet block (or the light block for radial light textures, written from the sheet block with no figure), the facing sentence for each figure, the layout line and `Image size`.

Rows: `proj_hush_torrent`: 3, `proj_water_jet`: 3, `proj_wax_hook`: 3, `light_glow_warm`: 3, `light_glow_cold`: 3, `light_shaft`: 3.

## `proj_hush_torrent`

### b50_proj_hush_torrent_v1

- Job id: `b50_proj_hush_torrent_v1`
- Output file: `tools/source_art/proj_hush_torrent_v1.png`
- Key colour: pure magenta `#FF00FF`
- Size: 1536x1024, 5 poses in 1 row
- Reference images: none (the style is in the shared block; no reference is attached)
- Variant: 1 of 3
- Accepted name after the cull: `tools/source_art/proj_hush_torrent.png`

```text
Original game art for "Wickwarden", a painterly top-down adventure. Hand-painted storybook illustration style with visible brush strokes and soft edges, high detail, warm lamp light against deep dusk colours, low saturation except for light sources. NOT pixel art, no pixel grid, no dithering, no thick black outlines. Three-quarter top-down view, camera about 50 degrees above the ground, key light from the upper left. No text, no letters, no numbers, no labels, no frame borders, no grid lines, no watermark.

A sprite sheet on a perfectly flat, uniform pure magenta #FF00FF background that fills the whole image, with no gradient, no texture, no vignette, no floor and no cast shadow on the background. Each pose is a separate, complete figure with a wide empty gap of background on all sides; poses never touch or overlap and nothing is cut off at the image edge. Poses in one row stand on one shared invisible ground line and have the same scale. The figure is identical in every pose: same design, same colours, same proportions.

A homing bolt of pale violet light: a small violet-white orb with a dark smoky core and a thin wisp trail. Impact: a violet puff of smoke and fading light. Exactly 5 separate poses in one horizontal row on a 1536x1024 landscape canvas, all at the same scale, centred on one common horizontal line, wide equal gaps. Poses 1 and 2: the projectile in flight, pose 2 a little further along its path. Poses 3 to 5: the impact where it lands; pose 3 the first flash, pose 4 the spread, pose 5 fading to a few flecks. Variation for this image: Neutral, clear composition. No extra poses, no cropping, no touching. Painterly high detail, no pixel art, no text.

Image size: 1536x1024.
```
