# Batch 12 prompts (18 images)

Source: `docs/art-inventory.md` section 4, row B12. Run recipe, prompt rules and file layout: [README.md](README.md). Hi-fi painterly art, never pixel art. The three variants of a unit differ in composition and detail only, never in design. Facing sheets (down and up) name the chosen side variant as their reference (see the reference line of each entry).

Rows: `tex_cave_stone_ground`: 3, `tex_cave_stone_wall`: 3, `tex_cave_stone_wall_face`: 3, `tex_cave_root_ground`: 3, `tex_cave_root_wall`: 3, `tex_cave_root_wall_face`: 3.

Shared rules used in every entry: the shared block of `art-brief.md`, then the sheet block, the texture block or the face block, as the entry says. Icons and single edge strips use the same wording with the key colour replaced (the icon block and the edge block are written from the sheet block and the edge-strip rule of `asset-contract.md` section 7; nothing else changed). Each entry ends with `Image size`.

### b12_tex_cave_stone_ground_v1

- Job id: `b12_tex_cave_stone_ground_v1`

- Key colour: not applicable (no key colour)
- Size: 1024x1024 (square), one seamless texture, facing `none (one direction)`
- Reference images: `tools/source_art/tex_wall_ruin.png` (style and design; attach them to the image call)
- Variant: 1 of 3
- Accepted name after the cull: `tools/source_art/tex_cave_stone_ground.png`

```text
Original game art for "Wickwarden", a painterly top-down adventure. Hand-painted storybook illustration style with visible brush strokes and soft edges, high detail, warm lamp light against deep dusk colours, low saturation except for light sources. NOT pixel art, no pixel grid, no dithering, no thick black outlines. Three-quarter top-down view, camera about 50 degrees above the ground, key light from the upper left. No text, no letters, no numbers, no labels, no frame borders, no grid lines, no watermark.

A cave floor of pale cut stone slabs with fine grey veining and a faint polished sheen, the slabs fitted in an irregular grid with thin dark joints; neutral value range, light to mid grey, no colour cast so the code can tint it per cave.

Variation for this image: Neutral, clear composition.
```
