# Batch 15 prompts (18 images)

Source: `docs/art-inventory.md` section 4, row B15. Run recipe, prompt rules and file layout: [README.md](README.md). Hi-fi painterly art, never pixel art. The three variants of a unit differ in composition and detail only, never in design. Facing sheets (down and up) name the chosen side variant as their reference (see the reference line of each entry).

Rows: `husk_hound_states`: 3, `brine_crab_walk`: 9, `brine_crab_states`: 3, `wickling`: 3.

Shared rules used in every entry: the shared block of `art-brief.md`, then the sheet block, the texture block or the face block, as the entry says. Icons and single edge strips use the same wording with the key colour replaced (the icon block and the edge block are written from the sheet block and the edge-strip rule of `asset-contract.md` section 7; nothing else changed). Each entry ends with `Image size`.
