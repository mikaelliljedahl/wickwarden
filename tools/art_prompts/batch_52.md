# Batch 52 prompts (12 images)

Source: `docs/art-inventory.md` section 4, row B52. Run recipe, prompt rules and file layout: [README.md](README.md). Hi-fi painterly art, never pixel art. The three variants of a unit differ in composition and detail only, never in design. Walk sheets are drawn side first (the accepted side sheet is the design reference for the down and up sheets); action sheets name the walk sheet of their own facing as their design reference (see each reference line). Producer f (batches 48 to 59), wording and facing rules from `tools/art_prompts/PROGRESS.md` and `PROGRESS_a.md`; invented details in `DESIGNS_f.md`.

Shared rules used in every entry: the shared block of `art-brief.md`, then the sheet block (or the light block for radial light textures, written from the sheet block with no figure), the facing sentence for each figure, the layout line and `Image size`.

Rows: `npc_keeper`: 3, `npc_villager_a`: 9.
